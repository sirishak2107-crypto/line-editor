# Simple Line Editor - Help

## Commands

### insert <line number>
Inserts a new line at the specified line number.

Example:
insert 2

The program will ask for the text of the new line.

### delete <line number>
Deletes the line at the specified line number.

Example:
delete 2

### display
Displays all lines in the document with their line numbers.

Example:
display

### help
Displays all available commands.

Example:
help

### exit
Closes the editor.

Example:
exit
